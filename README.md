# HF Lalamilo packhouse — published pages

Static mirror of `packhouse/` from the private `greenhouse-quote-tracker` repo, published so
the drawings have a live URL instead of a snapshot that goes stale.

**https://lfeder.github.io/hf-packhouse/**

Do not edit anything here. The source of truth is `greenhouse-quote-tracker/packhouse/`; run
`./publish-pages.sh` there and it syncs and pushes. Each commit message here names the source
commit, so you can always tell which version is live.

Link-only by intent: `robots.txt` disallows crawlers and the landing page is `noindex`. That
keeps it out of search results — it does not make the URL private. Nothing priced lives here;
budgets and vendor quotes stay in the private repo.
